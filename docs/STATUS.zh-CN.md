# 扩容前功能状态与已知限制

本表对应本机首次完成安装、驱动部署并确认可用桌面的阶段。没有将之后的扩容或后续反馈混入本阶段验证。

| 项目 | 结果 | 证据层级 |
|---|---|---|
| 系统版本 | macOS Sequoia 15.7.9 / 24G830 | 已安装系统版本文件与安装日志 |
| 系统启动 | OpenCore 可启动 Macintosh HD | 实际启动与机主反馈 |
| 账户登录 | 本地管理员可登录桌面 | 原生认证、权限、主目录与 Secure Token 检查，加实际登录反馈 |
| Windows | 原加载器和 EFI 文件保持，默认优先启动 Windows | 修改前后读取和哈希核对 |
| Wi-Fi | 可用，AX203、AirportItlwm、内置 en0 | 设备和接口记录，加机主联网反馈 |
| NVIDIA 系统驱动 | NVRM、NVAccel、NVRMFB、NVRMAGDC 均为 2.5.4 | 扩容前原系统备份中的实际元数据 |
| 显示日常使用 | 安装驱动后反馈正常 | 机主反馈；没有独立基准或长期压力测试 |
| CPU | 保留 cpus=1 | 实际最终 EFI；全核兼容性未解决 |
| Intel 核显 | 未验证加速 | 不能由 Intel 型号相近推定可用 |
| 原始地区页故障 | 未证实根因已修复 | 经同意建立本地账户，绕过卡住的设置流程 |
| Apple ID | 登录界面与已有记录曾不一致，未闭环 | 原机记录和机主反馈 |
| AirDrop | 不可用 | 机主反馈 |
| 键盘、鼠标 | 足以操作安装、维护和桌面 | 实际交互；不代表所有输入功能 |
| 内置触摸板完整手势 | 未全面验证 | I2C 匹配仍有已知适配缺口 |
| USB | 默认映射组合，未逐端口验收 | 已配置 USBToolBox/UTBDefault，不等于映射完成 |
| 扬声器、功放、麦克风 | 未完整验收 | AppleALC 在配置中存在不等于实际全部工作 |
| 睡眠、唤醒、外接显示、长时间负载 | 未完整验收 | 没有足够测试记录 |

## 不应照搬的结论

- 不应把 `cpus=1` 写成“i9 全性能已经解锁”。
- 不应把第三方驱动说成苹果或 NVIDIA 官方原生支持。
- 不应把 Wi-Fi 可用写成 AirDrop、蓝牙和全部连续互通功能都可用。
- 不应把绕过 Setup Assistant 写成已经修复其地区页等待的根因。
- 不应把配置校验通过、隔离副本验证通过当成本机启动成功。
- 不应把 AppleHDA 阻断配置存在当成阻断成功，实际日志曾为 Unsupported。

当前仓库是经过证据整理的单机实践案例与重建参考，不提供对其他型号、其他 BIOS 或新系统版本的兼容承诺。
