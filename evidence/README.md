# 公开证据摘要的范围

`summary.json` 只保留经核对的技术结论、验证方式和少量非个人元数据，不复制原始 Verification 目录。

证据层次如下：

1. 硬件清单、显示路由测量和实际扩展元数据用于说明本机条件。
2. OpenCore 和 APFS 安装日志用于区分配置生效、安装阶段推进和部署完成。
3. 原生线程快照与程序方法定位用于说明地区页等待位置；不据此补写尚未建立的完整根因。
4. 原生账户检查报告与后续图形登录反馈用于说明账户流程结果。
5. 扩容前驱动元数据和机主当时的使用反馈用于说明 NVIDIA 安装后的可用状态；不采用之后扩容阶段的显卡反馈替代本阶段证据。

敏感的源日志、完整截图、账户记录、实际 config、身份标识和系统备份留在私人资料中。公开摘要不是这些文件的完整替代，也不是独立实验室认证。

本仓库新运行的检查仅针对文档、文件清单、配置脱敏和字符串示例。没有为发布报告重新启动电脑、修改 EFI、重分区、安装驱动或创建账户。
